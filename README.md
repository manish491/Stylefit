# StyleFit - Merged E-Commerce Platform

This repository represents the merged codebase combining `style-fit` core components with modular interactive components, 3D visualizers, sections, and pages from `earlier-version-leftovers`.

## Features Integrated
- **3D Visualization**: Three.js Hero & Viewer scenes for interactive product rendering.
- **E-Commerce Flow**: Integrated Shopping, Cart, Wishlist, Product Details, and Collection Index pages.
- **UI Components**: Toast notifications, Size Guide modal, Product Art, Quick View, and layout grids.
